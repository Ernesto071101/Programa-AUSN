# Monitor de Red - Visualización de Cámaras y Equipos IP

Este es un programa en Python diseñado para ayudar a a los técnicos a monitorear rápidamente el estado de conexión de diferentes dispositivos IP (como cámaras de seguridad, routers, grabadores, etc.). 
El programa realiza un **ping** a una lista de direcciones IP y,  **abre automáticamente su interfaz web** en el navegador predeterminado dependiento el dispositivo.

## 🛠 Características

- ✅ Realiza ping a una lista de direcciones IP configurables.
- 🌐 Abre automáticamente URLs en el navegador si los dispositivos están activos.
- 📷 Diseñado para monitorear cámaras IP, READER y otros dispositivos accesibles vía web.
- ⚙️ Fácil configuración a través de un archivo de lista o directamente en el código.
- 💻 Interfaz simple y directa.


## 🚀 Cómo usar

1. Asegúrate de tener Python 3 instalado.

2. Instala los requerimientos si aplica (aunque no se requieren paquetes externos básicos).

3. Ejecuta el script.
